Example problem: Find the sum of all positive integers $n$ such that $n^2 - 19n + 99$ is a perfect square.
Example solution: Let $n^2 - 19n + 99 = m^2$ for some non-negative integer $m$. Then $(2n-19)^2 - 4m^2 = 19^2 - 4(99) = 361 - 396 = -35$. So $4m^2 - (2n-19)^2 = 35$, meaning $(2m - (2n-19))(2m + (2n-19)) = 35$. Since $35 = 1 \times 35 = 5 \times 7$, we get solutions $n = 1, 9, 10, 18$. The sum is $\boxed{38}$.
